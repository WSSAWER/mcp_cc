# MCP Control Center — 1C Edition

В этой поставке только **1C Database** и **1C XML Editor**. Настройки подключений,
пароли и рабочие данные с компьютера разработчика не включены.

## Запуск и подключение

Требуется Windows x64 с .NET 7 Desktop Runtime; Git нужен для установки и обновления MCP.
Запустите `McpControlCenter.exe` без повышения прав. MCP запускаются кнопкой Start,
а не автоматически. Укажите свободный Unified port в окне CC: в свежей поставке
он равен 0 (выключен), чтобы не конфликтовать с другой установленной копией.
Подключение клиента: `http://127.0.0.1:<Unified port>/mcp`, Streamable HTTP.
Отдельные внешние порты MCP по умолчанию выключены. Для сетевого доступа отдельно
настройте Gate и правила firewall; эта поставка не добавляет авторизацию к файловым
инструментам, поэтому не публикуйте её в недоверенную сеть.

Внутренние порты: Database — 11610, XML — 11614. Если они заняты другой копией,
измените их в таблице до запуска. Папку можно переносить целиком: команды используют
`{APP_DIR}`, а данные каждого MCP находятся в `mcps/<id>/.generated`.

## Два инструмента

- **1C Database** устанавливается из `WSSAWER/onec_database`, ветка `release`.
  Его собственный README находится в `mcps/onec-database/server` (также пункт Help).
  Базы настраиваются его инструментами; новая поставка не содержит ни одной базы.
- **1C XML Editor** устанавливается из `WSSAWER/1c_xml`, ветка `release`.
  Это C# MCP-оболочка CC над установленным `1C_XML.exe`, без Node и shell-команд.
  Штатные MCP-схемы считываются из EXE при старте, а не дублируются вручную.
  CC использует ASCII `wireName`; JSON-параметры без потери типов передаются
  через `mcp-call --stdin-json`. `xml_help` объясняет конкретную CLI-команду. Пути относятся к компьютеру,
  где запущен MCP. Операции меняют файлы XML/BSL; загрузка в настоящую ИБ — отдельный
  явно разрешённый этап через Database. Журналы: `logs/control-center/onec-xml/commands`.
  Справочник: `mcps/onec-xml/server/docs/reference/README.md`.

## Обновления и состав

Update / Reinstall обновляет программу выбранного MCP; Program сохраняет рабочие
данные. Обновление приложения и общих конфигов доступно в Services.
Оно **не добавит остальные MCP**: состав фиксирует отдельный
`mcp-distribution.json`, который штатное обновление не заменяет. Он применяется
при загрузке, обновлении профилей, установке, запуске и формировании Unified tools.
Даже с Admin-токеном эта поставка не публикует встроенную админку.

Не удаляйте `mcp-distribution.json`: это ограничение состава поставки, не защита
от владельца компьютера, который сам изменяет её файлы.

## Повторная сборка

В репозитории CC: Debug → smoke-тесты → Release → Release smoke-тесты,
затем `.agents/package-1c-edition.ps1 -Destination <новая папка>
-VerifiedDatabaseExe <проверенный OneCDatabase.exe> -VerifiedXmlExe <проверенный 1C_XML.exe>`.
Хеши скачанных EXE обязаны совпасть с проверенными сборками.
Существующая установка этой командой не перезаписывается.
